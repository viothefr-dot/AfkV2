# Browser Play mode

This build adds a browser Play panel using prismarine-viewer. It renders the connected Mineflayer bot's world view and provides WASD/jump controls.

It is not a full browser-native Minecraft Java client. A full client would require a different protocol/WebGL architecture.

Optional automation:
- Auto-hit nearby players every 7 seconds
- Auto-eat when food is low

These options are disabled by default and should only be used on servers where automation is explicitly permitted. The project does not bypass authentication, CAPTCHA, anti-bot, or anti-cheat systems.

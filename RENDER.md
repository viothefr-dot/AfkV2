# AFKCloud Render deployment

Build command: `npm install`
Start command: `npm start`

Render environment variables are optional for the dashboard because the server settings are entered in the UI. Render supplies `PORT` automatically.

Features:
- Responsive glass-style dashboard
- Minecraft version selector
- Live chat viewer and message input
- Start/stop bot
- Auto reconnect-ready status controls
- Browser-local saved profiles
- Uptime/status cards
- Configurable rotation interval
- Render PORT support

Use automated clients only on servers that permit them. This project does not bypass authentication, anti-bot, or anti-AFK protections.
